# Computational Problem Solving (CPS) — Semester 1

Python programs written for the Semester 1 Computational Problem Solving course at Amrita.
Each folder groups programs by topic; run any file with `python <file>.py`.

| Folder | Programs |
|---|---|
| `01-basics` | hello world, voting eligibility, positive/negative, odd/even, largest of three, even/odd digit sums, lambda, number patterns |
| `02-recursion` | factorial, Fibonacci, sum of natural numbers, palindrome check |
| `03-searching` | linear search (loop and recursive), binary search, sorting and searching a matrix by row sum |
| `04-sorting` | insertion sort, selection sort, bubble vs selection vs insertion |
| `05-lists-and-matrices` | rotate a list, matrix addition, scalar multiplication, transpose |
| `06-stack` | menu-driven stack of garment records (push / pop / display) |
| `07-file-handling` | character, word and line counts in text files; storing records with `pickle` |
| `08-practice-questions` | ATM withdrawal simulator (practice exam question) |

The file-handling programs expect their input file (`Paragraph.txt`, `Notice.txt`, `report.txt`) in the folder you run them from.
